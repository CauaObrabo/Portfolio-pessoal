# Portfólio pessoal

Portfólio de página única desenvolvido com Next.js App Router, TypeScript, Tailwind CSS e Framer Motion.

## Começar

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) para visualizar.

## Personalização

- Edite nome, apresentação e canais de contato em `data/profile.ts`.
- Atualize habilidades, formação, certificados, projetos e hobbies nos arquivos correspondentes em `data/`.
- Troque as iniciais `SN` no avatar e no cabeçalho em `components/sections.tsx` e `components/header.tsx`.
- O formulário usa `mailto:` e depende de um aplicativo de email configurado no dispositivo.
